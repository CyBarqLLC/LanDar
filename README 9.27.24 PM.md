# موقع لاندار

موقع ثابت بلغتين، مبني بـ HTML و CSS و JavaScript فقط، بلا أي مكتبات.

## الملفات

- `index.html` الصفحة العربية
- `en/index.html` الصفحة الإنجليزية
- `assets/css/style.css` التنسيق، مبني للجوال أولاً
- `assets/js/main.js` القائمة، لوحات النموذج التوضيحي، حاسبة الكلفة، والنماذج ثلاثية الأبعاد
- `assets/img/` الصورة والأيقونات

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد كما هي إلى مستودع على GitHub.
2. من Settings ثم Pages اختر الفرع `main` والمجلد `/root`.
3. بعد دقيقة يظهر الموقع على رابط المستودع.

كل الروابط داخل الموقع نسبية، فيعمل على أي رابط أو نطاق دون تعديل.

## تعديلات شائعة

- **السعر:** القيم `RATE` (سعر المتر) و `TIER` (حدّ الشريحة الأولى بالمتر المربع) و `RATE_ABOVE` (سعر المتر بعد الحدّ) و `LAND` (سعر متر اللاندسكيب) و `MODEL` (النموذج ثلاثي الأبعاد) في أعلى قسم الحاسبة داخل `assets/js/main.js`، والنصوص وقائمة الأسعار في الصفحتين.
- **الهاتف والبريد:** ابحث عن `962789227303` و `hello@landar.net` (البريد العام) و `nawras@landar.net` (بريد م. نورس) في الصفحتين.
- **واتساب:** كل روابطه تبدأ بـ `https://wa.me/962789227303`، والرسائل الجاهزة مكتوبة بعد `?text=`.
- **حسابات التواصل:** ابحث عن `landarStudio` في الصفحتين.
- **النماذج ثلاثية الأبعاد:** كل نموذج قائمة صناديق في `MODELS` داخل `assets/js/main.js`.
- **النموذج التوضيحي:** لوحاته الأربع (المعماري، الكهرباء، التكييف، اللاندسكيب) رسوم SVG مكتوبة داخل الصفحتين مباشرة.

## الخط

الموقع يستخدم خط ثمانية إن كان مثبتاً على جهاز الزائر، وإلا يعرض IBM Plex Sans Arabic من Google Fonts. ملفات خط ثمانية غير مرفوعة مع الموقع لأن ترخيصه يمنع استضافتها للتنزيل.
